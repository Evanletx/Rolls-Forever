## Introduction

> **I don't know about you, but I haven't won anything since 2006.**
> **Rolls Forever lets you find out if that's actually true.**

This mod automagically keeps a record of every Need and Greed roll you make in WoW Forever, on every character.

---

## How it works

Each time an item comes up for a roll, Rolls Forever notes the item, whether you picked **Need**, **Greed** or **Pass**, the number you rolled, who won and what they rolled.

View rolls per character, and you can switch between or look at all of them together.

Open it with `/rolls`, the minimap button, or the addon menu on the minimap.

| | Feature | |
| :---: | :--- | :--- |
| 🗂️ | **Tabs** | All Rolls, Need and Greed |
| 👤 | **Character dropdown** | Each character on its own, or an All Characters view |
| 📅 | **Calendar filter** | Pick a date and look back 30 days, 60 days, 3, 6 or 9 months, a year, or all time |
| 🔎 | **Search box** | Find an item, a winner or a location by name |
| 📊 | **Stats panel** | Median, highest and lowest roll, natural 100s and 1s, luck, win and dry streaks, closest loss, and where you roll the most |

---

## Install

1. Download or clone this repository.
2. Put the folder in your WoW Forever addons folder, named `RollsForever`:
   ```
   World of Warcraft/_forever_/Interface/AddOns/RollsForever
   ```
3. Restart the game (or `/reload`) and make sure **Rolls Forever** is ticked in the AddOns list.

---

## Commands

| Command | What it does |
| :--- | :--- |
| `/rolls` | Opens or closes the window. `/rf` and `/rollsforever` work too. |
| `/rolls scale 0.9` | Makes the window smaller or bigger, anywhere from `0.6` to `1.5`. |
| `/rolls minimap` | Shows or hides the minimap button. |
| `/rolls reset` | Wipes the saved rolls for the character you're on. Asks you to type `/rolls reset confirm` first. |
| `/rolls about` | Version, credits and where to get help. |
